Access to Programs & DataCommon Control Narrative

Defines the governance, control design and operational procedures supporting Access to Programs and Data controls for the in-scope applications that follow the common access management process, covering user lifecycle management, access provisioning and modification, access revocation, periodic access reviews, privileged access, authentication and segregation of duties.

Process model

The access management lifecycle

SAP HR is the authoritative source for permanent employee lifecycle events, SailPoint manages identity lifecycle processing, and ServiceNow manages application access requests and approval workflows. Select a stage for the detail.

Provisioning and revocation capability varies by application and connector type. Applications integrated through two-way connectors support direct provisioning and revocation through SailPoint. One-way or read-only integrations support aggregation only, requiring fulfilment through ServiceNow requests and / or manual activities.

Common Change ManagementControl Narrative

Defines the governance, control design and operational procedures supporting Change Management controls. The process ensures that changes are appropriately authorised, risk-assessed, tested, approved, implemented and reviewed before deployment into production environments, supporting the effectiveness of internal controls over financial reporting.

Process model

From request to closure

The process is operated through an enterprise ITSM platform and supported by a structured governance model including request submission, technical review, QA, Service Manager oversight and CAB governance. Select a stage for the detail.

The route taken depends on the change classification. Standard changes execute against a pre-approved template. Implementation before completion of the normal approval route is permitted only through the approved emergency-change process, and a change ticket remains mandatory.
Classification

Five change classifications

The selected classification determines the applicable assessment, approval, testing and governance route. Select a classification for the detail.

Failed changes

Failed change management

A change is treated as failed where it does not achieve the intended outcome or results in an incident. It is not closed simply by recording an unsuccessful result.

The control set

Change Management controls

CM.C01 to CM.C09. Select a control for its objective, frequency, roles involved, exception handling, applicability and evidence requirements.

Coverage

Applicability by application

The starting position is taken from the applicability statement under each control, including the qualifying condition where one is stated. Hover a control column for that condition. Turn on editing to set applicability yourself, control by control; changes are held in this browser and can be exported to a file.

Accountability

Roles and responsibility ownership

Change Management roles and approval responsibilities are configured through ServiceNow workflow roles, assignment groups and approval groups. Membership of the relevant authorised groups determines who may raise, review, approve or implement changes.
